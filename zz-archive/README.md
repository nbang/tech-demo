# zz-archive

Finished or abandoned demos, kept for reference. The `zz-` prefix keeps this
folder at the bottom of the repo listing.

Nothing here is maintained: model IDs, endpoints, and dependencies are likely
stale. Read it, don't run it as-is.

| Folder | What it was | Archived | Why |
|---|---|---|---|
| `openfang-guide/` | OpenFang setup guide + example `config.toml` | 2026-10-15 | Upstream GitHub project looks frozen |

To archive a demo: `git mv <project> zz-archive/<project>`, add a row above,
and remove its row from the table in the root `AGENTS.md`.
