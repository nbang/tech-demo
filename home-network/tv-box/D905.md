# D905 retro box

Unbranded budget retro-gaming box. **Broken:** Android on the NAND freezes at
the logo, and its old EmuELEC SD card is failing. Not on the network. Plan:
skip Android and run a fresh EmuELEC card from SD.

## The box

| | |
|---|---|
| SoC | **Amlogic S905L** per two seller leaflets (GXL, `p281` board). Chip under the heatsink, not read. Confirm with `dmesg \| grep -i "Amlogic Meson"` on Linux ≥ 6.11 (`GXLX (S905L)` vs `GXL (S905W)`) |
| RAM | 1 GB DDR3 (2× Samsung `K4B4G1646E`) |
| Storage | **8 GB raw MLC NAND** (Micron `MT29F64G08CBABB`), **not eMMC**. Armbian can't install to it |
| Ethernet | 10/100, SoC **internal PHY** (only magnetics next to the RJ45) |
| Android | `Amlogic/p281/p281 10/NHG47L/20210406 userdebug/test-keys` (really 7.1.2) |
| Wi-Fi / MAC / IP | unknown |
| UART | likely the 3-pin header top left, by R34–R36 (GND/RX/TX, 3.3 V, 115200 8N1) |

- The "Android" logo is the u-boot splash. It shows even when booting EmuELEC.
- Recovery: unplug, hold a toothpick in the **AV jack**, plug in, hold 10–15 s.
  Navigate with the remote.

## State (2026-10-11)

- Normal boot **freezes** on the logo. Recovery works, but wipe cache and
  factory reset didn't help, so `/system` or `/boot` is damaged. u-boot, power
  and RAM are fine.
- **No matching Android firmware exists.** Searches found only S905W/eMMC
  builds or other S905L boards (wrong image = failed flash or a dead NAND), and
  XDA requests for other D905 builds (`p201`, `20190924`) with no download.
  Decision: don't reflash Android.
- The old 62.5 GB card (`EMUELEC` boot / `STORAGE` saves / `EEROMS` ROMs) reads
  at ~1.5 MB/s with I/O errors. A `ddrescue` rescue was started 2026-09-26 and
  **its result was never checked**.

## Next steps

1. *(Optional)* In recovery, **Mount /system** and **View recovery logs**; note
   any NAND/I/O errors.
2. **Fresh EmuELEC card** on a spare SD card (≥ 8 GB, never the old one):
   ```bash
   # EmuELEC-Amlogic-ng.aarch64-4.8-Generic.img.gz from github.com/EmuELEC/EmuELEC/releases (4.7 as fallback)
   shasum -a 256 -c *.sha256
   diskutil list external; diskutil unmountDisk /dev/diskN
   gunzip -c EmuELEC-Amlogic-ng.aarch64-4.8-Generic.img.gz | sudo dd of=/dev/rdiskN bs=4m
   ```
   On the `EMUELEC` partition copy `device_trees/gxl_p281_1g.dtb` to the root
   as `dtb.img`. If the box ignores the card: recovery → *Apply update from EXT*
   → `aml_autoscript.zip`.
3. Check the rescue (needs the owner's OK to SSH in). [d905-rescue.sh](d905-rescue.sh)
   ran in tmux on the TX3 (card in its slot as `mmcblk1`, set read-only) and
   wrote over sshfs to the Chainedbox, which has since moved to `192.168.2.10`:
   - image `/srv/dev-disk-by-label-data/backups/d905/sdcard-emuelec.img` + `.sha256`
   - mapfile `/root/d905-sdcard.map` on the TX3; rerun the script to resume
   - done when `ddrescuelog -t` shows 100%
4. If complete: `zstd` it **to a file** on the Chainedbox, `rclone copy` to
   `gdrive:backups/d905/`, restore-test against the `.sha256`. Then remove the
   temporary `tx3-d905-rescue` key from the Chainedbox's
   `/root/.ssh/authorized_keys` and `fusermount -u /mnt/chainbox` on the TX3.
5. Restore the games: write the image to a **≥ 64 GB** card, then on Linux
   `fsck.vfat -a` p1 and p3, `e2fsck -f -y` p2. For files only:
   `losetup -Pr` the image and mount `p3` (ROMs, BIOS) and `p2` (saves).

## Gotchas

- Never write to, fsck, or mount read-write the **original** card. On macOS its
  dirty FAT hangs fskit: `sudo pkill -9 -f com.apple.fskit.msdos`.
- [d905-backup-sd.sh](d905-backup-sd.sh) / [d905-backup-sd-onepass.sh](d905-backup-sd-onepass.sh)
  (Mac → Drive streaming) are only for healthy cards: `dd conv=noerror,sync`
  zero-filled the rest when this card dropped off USB.
- **"LAN not detected" = wrong dtb.** Use an internal-PHY one: `gxl_p281_1g`
  (EmuELEC/CoreELEC) or `meson-gxlx-s905l-p271` / `meson-gxl-s905w-p281`
  (mainline). Not random 2019 dtbs built for kernel 3.14. The seller's working
  dtb is `dtb.img` in the rescued image.
- Other OS options: CoreELEC 21.3 is the last release with GXL; Armbian (ophub
  S905L boards) only from SD/USB, as a weaker TX3.
- `rclone` `gdrive:` token expired: `rclone config reconnect gdrive:`.
